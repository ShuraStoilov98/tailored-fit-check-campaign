# 13 — UX Brand-Consistent Polish

## Project

Tailored Fit Check Campaign App

## Objective

Apply a precise brand-consistency polish pass to the Fit Check campaign web app.

This is a **visual/typography polish task only**. The app already works end-to-end. Do not change core logic, OpenAI logic, lead capture, Google Sheet logging, Railway setup, campaign tracking, or backend behaviour.

The goal is to make the campaign feel closer to the Tailored brand: refined, premium, clean, and consistent with the app’s visual direction.

# CSS Implementation Notes

Prefer central CSS variables near the top of `static/styles.css`.

Suggested:

```css
:root {
  --page-bg: #F8F8FF;
  --occasion-selected: #D0B98C;
  --font-serif: "Playfair Display", serif;
  --font-sans: "Manrope", system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
}
```

Update Google Fonts import if needed to include Manrope:

```css
@import url("https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700&family=Playfair+Display:wght@400;500;600&display=swap");
```

Keep Playfair Display regular where requested. Avoid heavy bold Playfair unless already needed for visual hierarchy.
